# FasalKart 🌱

FasalKart is an online marketplace web application where farmers sell crops and fresh produce directly to buyers with zero middlemen.

## ✨ Features

- **Direct Farm Marketplace**: Connects urban households and buyers directly with verified rural farmers.
- **Visual Design**: Forest green (`#1B5E20`), warm harvest gold (`#F9A825`), and creamy off-white (`#FAF8F3`) palette with glassmorphism and subtle micro-interactions.
- **Smooth Animations**: Animated transitions, hover effects, cart drawers, and toast alerts powered by Framer Motion.
- **Pages**:
  - **Home**: Dynamic hero, location selector, category chips, "Fresh Today" & "Best Sellers" carousels, "How It Works" 4-step workflow, farmer cards, testimonials, and trust badges.
  - **All Produce**: Real-time search, category filter, price slider, rating filter, organic checkbox, sorting, and grid/list toggles.
  - **Product Details**: Image gallery with thumbnails, price per unit, farmer heritage card, reviews tab, and related produce recommendations.
  - **Cart**: Quantity adjuster, coupon code engine (`FARM50`, `ORGANIC`), and free-delivery progress tracker.
  - **Checkout**: 3-step interactive flow (Address ➔ Payment ➔ Review & Confirm) with animated success screen and generated Order ID.
  - **Farmer Dashboard**: Interactive monthly revenue and harvest charts with Recharts, metric cards, and a modal to list new harvest crops.
  - **Login / Register**: Persona toggle for Buyer vs Farmer.
  - **Responsive Design**: Mobile-first layout with sticky bottom navigation bar.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/Durva46/FasalKart.git

# Enter project directory
cd FasalKart

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production
```bash
npm run build
```
